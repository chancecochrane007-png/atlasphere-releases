# Atlasphere

One library for every PC game store: Steam, Epic Games, GOG, Xbox, EA app, Ubisoft, Rockstar Games, Battle.net and Amazon Games.

**Download:** grab `Atlasphere-Setup-x.y.z.exe` from the [latest release](../../releases/latest) and run it. After that, Atlasphere keeps itself up to date from this page.

This repository only holds the published installers. New versions are published automatically by the workflow in `.github/workflows/publish.yml`.
